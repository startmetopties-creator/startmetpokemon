Over BREAKpoint

BREAKpoint is een set uit de XY-serie van het Pokemon-ruilkaartspel, uitgebracht op 3 februari 2016. De set telt 122 kaarten in de hoofdset en 126 kaarten inclusief de secret rares. Op deze pagina vind je de kerngegevens en de complete, doorzoekbare kaartlijst.

Waar BREAKpoint in de tijdlijn past, zie je in ons overzicht van alle sets op volgorde. Wat er op dit moment uitkomt, staat op de release-kalender 2026. Hoe je sealed product en losse kaarten per set beoordeelt, lees je in Module 3 van de cursus.
