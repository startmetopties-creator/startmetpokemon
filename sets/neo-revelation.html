Over Neo Revelation

Neo Revelation is een set uit de Neo-serie van het Pokemon-ruilkaartspel, uitgebracht op 21 september 2001. De set telt 64 kaarten in de hoofdset en 66 kaarten inclusief de secret rares. Op deze pagina vind je de kerngegevens en de complete, doorzoekbare kaartlijst.

Waar Neo Revelation in de tijdlijn past, zie je in ons overzicht van alle sets op volgorde. Wat er op dit moment uitkomt, staat op de release-kalender 2026. Hoe je sealed product en losse kaarten per set beoordeelt, lees je in Module 3 van de cursus.
