De set in het kort

De Base Set is waar het Engelstalige Pokemon-ruilkaartspel in 1999 begon. De set telt 102 kaarten, met 16 holografische zeldzame kaarten die bepaalden hoe zeldzaamheid er in de hobby uit zou gaan zien. Voor veel verzamelaars is dit de heilige graal, met de holo Charizard als absolute icoonkaart.

De Base Set bestaat in meerdere edities die de waarde sterk bepalen. De 1st Edition (met een klein stempel) is het zeldzaamst en het duurst, gevolgd door de Shadowless (zonder slagschaduw rond het kader) en de veel ruimer gedrukte Unlimited. Een 1st Edition holo Charizard in hoge grading is een van de bekendste en duurste moderne verzamelobjecten.

Waar Base Set in de serie past, zie je in ons overzicht van alle sets op volgorde. Wat er nu uitkomt, staat op de release-kalender 2026.

De chase cards

De holo Charizard (4/102) is met afstand de bekendste kaart van de set en een van de beroemdste Pokemon-kaarten ooit. Daarnaast zijn de holo Blastoise (2/102) en holo Venusaur (15/102) geliefd als de andere twee starter-eindvormen. De 16 holo's samen vormen de kern van elke Base Set-verzameling.

Vragen over Base Set

De Engelstalige Base Set verscheen begin 1999 en is de allereerste Pokemon-set in het Westen. De originele Japanse basisset verscheen al in 1996.
De Base Set telt 102 kaarten, waarvan 16 holografisch. Er zijn geen secret rares; dat concept kwam pas in latere sets.
1st Edition-kaarten hebben een klein 1st Edition-stempel en zijn het zeldzaamst en duurst. Shadowless-kaarten missen de slagschaduw rechts van het kader en zitten daartussenin. Unlimited-kaarten zijn het ruimst gedrukt en het meest betaalbaar.
