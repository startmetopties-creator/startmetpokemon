Over Platinum

Platinum is een set uit de Platinum-serie van het Pokemon-ruilkaartspel, uitgebracht op 11 februari 2009. De set telt 127 kaarten in de hoofdset en 133 kaarten inclusief de secret rares. Op deze pagina vind je de kerngegevens en de complete, doorzoekbare kaartlijst.

Waar Platinum in de tijdlijn past, zie je in ons overzicht van alle sets op volgorde. Wat er op dit moment uitkomt, staat op de release-kalender 2026. Hoe je sealed product en losse kaarten per set beoordeelt, lees je in Module 3 van de cursus.
